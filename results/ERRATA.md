# Errata to Earlier Stage Reports

Stage reports under `results/` are frozen records of what was run and concluded at the time; they are not rewritten. Corrections are listed here, dated, with the evidence that supersedes each statement. The README carries matching correction notes.

---

## 2026-09-19

### E1. Stage J2c bulk offset at Pitiscus is wrong
- **Where:** `UPGRADE_J_DENSE.md` section 2 (J2c); `UPGRADE_K_COARSE_FINE.md` section 1 (K1); `UPGRADE_L_GEOMETRIC_FILTER.md` (applied throughout); README Stage J item 1 and Stage K item 1.
- **Stated:** a-priori TMC-2 to NAC offset (-82.12, +224.04) common-grid px = 1,126.29 m, "phase correlation offset across central overlap".
- **Evidence:** `UPGRADE_N_CORROBORATION.md` sections 0 and 3.4. On the full valid strip, independent phase correlation gives (+87.65, +799.51) px (PSR 54.45; controls at most 8.58). Four 2,000-row segments reproduce it. Non-circular NCC gives mean +0.468 at that lag against -0.035 at the J2c lag. `cv2.phaseCorrelate` returns (+87.01, +799.31). Stage O then registers 1,607 of 1,781 nodes starting from this offset (`UPGRADE_O_REGISTRATION.md`).
- **Consequence:** the Stage K/L search windows (radius 32 px) were centred about 600 px from the true match. No Stage K or L node could contain its true correspondence.
- **Open:** the script that produced the J2c value is not in the repository, so the origin of the error is unknown.

### E2. "Illumination is the primary / sole root cause" at Pitiscus is withdrawn
- **Where:** `UPGRADE_J_DENSE.md` section 5 (J7 item 2); `UPGRADE_K_COARSE_FINE.md` "Finding on Cause 1", sections 3 and 6; `UPGRADE_L_GEOMETRIC_FILTER.md` section 5 "Physical Mechanism"; `UPGRADE_M_SUBPIXEL_TRUTH.md` sections 4-5; README Stage M "Core Diagnostic Conclusion".
- **Evidence:** with the corrected offset, raw intensity NCC accepts 96.2% of nodes (mean peak 0.681) across the same 78.32 deg sun-azimuth difference (`UPGRADE_O_REGISTRATION.md`). The Stage K/L control parity (Delta_shuffle +0.54% / -0.54%) is fully explained by E1.
- **Still valid:** the Stage K/L GATED verdicts (the controls were correctly run and correctly failed the gate), and the Stage M estimator and resampling validation under matched illumination.

### E3. Half-pixel sampling convention in the Stage J-M common grid
- **Where:** `scripts/evaluate_stage_k.py`, `evaluate_stage_l.py` (NAC resampling: `(X - left) / 2` without `- 0.5`).
- **Effect:** the NAC orthophoto was sampled 1 m east and 1 m south of the stated map point (0.21 px at 4.72 m). This is negligible against the Stage K/L residuals, but not negligible for any sub-pixel statement.
- **Fixed in:** `src/lunar_reg/pitiscus_grid.py` (Stage O onward), with the product georeferencing verified against `rasterio.warp.reproject` (`UPGRADE_O_REGISTRATION.md` section 4).
